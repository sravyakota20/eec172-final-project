Project Overview

What Cloud Snake is and why it matters

Cloud Snake Leaderboard Console is an embedded systems project that turns a simple game into a complete interactive hardware system. Instead of just displaying graphics, the project combines real-time user input, OLED rendering, local score storage, and cloud communication into one polished experience.

Next: Architecture Back to Home

Main idea

The goal of this project is to build a standalone gaming console using the CC3200 LaunchPad. A player interacts with the system using an IR remote, watches gameplay on a color OLED display, and submits scores to a cloud-connected leaderboard. This makes the project a strong example of how embedded systems can combine hardware control, communication protocols, and user-facing design in a single application.

Why we chose it

We wanted a project that was visually impressive, technically meaningful, and realistic to demonstrate in class. Snake is familiar and easy to understand, but the full system behind it shows much more than gameplay. It highlights responsiveness, communication between components, and the ability to connect a local embedded device to a cloud-based webpage.

Key features

🎮
Interactive gameplay
The user controls Snake in real time through an IR remote, creating a responsive embedded interface without using a keyboard or touchscreen.
🖥️
Color OLED graphics
The OLED display is used to show menus, gameplay, scores, and status information in a visually appealing way.
☁️
Cloud leaderboard
Scores are uploaded after each run so the companion webpage can show rankings and recent activity.
📡
Multi-protocol integration
The project uses embedded communication concepts like SPI, I2C, IR input handling, and Wi-Fi networking in one system.

What this project demonstrates

Cloud Snake is not just a game demo. It demonstrates how embedded systems can manage user interaction, hardware peripherals, display rendering, persistent data, and internet connectivity together. That makes it a strong final project because it shows both low-level technical skills and the ability to design an experience that looks clean, understandable, and engaging to users.
