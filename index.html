Overview

What this project does

Cloud Snake is an embedded systems project that combines interactive gameplay, hardware protocols, local persistence, and cloud connectivity into one polished console experience.

🎮

IR-Controlled Gameplay

Play your way with either an IR remote or the LaunchPad's onboard I2C sensor, letting you steer the snake, pause the action, and glide through menus with a simple tilt.

🖥️

Color OLED Display

Fast SPI-driven graphics on a 1.5-inch color OLED make the game feel responsive and polished.

☁️

Cloud Leaderboard

After each game, scores are uploaded to AWS IoT so a webpage can display top players and recent runs.
