System Architecture

How the hardware and software work together

The Cloud Snake Leaderboard Console is designed as a connected embedded system. The CC3200 acts as the central controller, coordinating player input, game logic, display rendering, local score handling, and cloud communication. This architecture lets the project feel interactive on the device while also extending the experience to a companion webpage.

System architecture diagram

This diagram shows the full project pipeline: the player controls the game through the IR remote, the CC3200 updates gameplay and renders to the OLED, then publishes score events to AWS IoT. Those events are stored in DynamoDB, read by Lambda, and finally displayed on the live leaderboard webpage.

High-level data flow

1. User Input

The player presses buttons on the IR remote to move the snake, pause gameplay, or navigate menus.

2. CC3200 Processing

The microcontroller decodes input, updates game state, manages timing, and controls the rest of the system.

3. OLED Rendering

Updated game graphics, score values, and interface screens are drawn to the color OLED using SPI communication.

4. Score Handling

After a session ends, the player score is saved locally and prepared for upload to the cloud leaderboard.

5. Web Display

The webpage retrieves leaderboard information and presents project results in a visually clear format.

Hardware components

  • CC3200 LaunchPad: main microcontroller and Wi-Fi platform for system control.
  • IR receiver: captures remote control signals for gameplay and menu navigation.
  • Color OLED display: shows the game screen, score, player interface, and status output.
  • Optional I2C sensor: supports future extensions such as extra motion-based interaction.

Software responsibilities

  • Input handling: read and decode IR commands reliably.
  • Game engine: manage snake movement, collisions, food generation, and score updates.
  • Display logic: draw menus, refresh frames, and present feedback to the player.
  • Networking: send leaderboard data through Wi-Fi to a cloud service.

Input Layer

The IR remote forms the user interaction layer. It is simple for demos, easy to understand visually, and well-suited for an embedded console experience.

Control Layer

The CC3200 executes the application logic, maintains game state, schedules updates, and bridges local hardware with internet-based features.

Presentation Layer

The OLED display and companion webpage work together to present both live gameplay and uploaded results in a polished way.

Why this architecture is effective

This design is effective because it separates interaction, control, display, and cloud communication into clear functional roles while still keeping the overall system manageable for a final project. It demonstrates embedded fundamentals such as peripheral integration and real-time updates, while also showing how a device can communicate beyond itself through a connected leaderboard webpage.
